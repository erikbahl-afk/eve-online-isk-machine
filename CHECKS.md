# One-time in-game checks (~10 min)

Do these on the trading character while docked in **Jita IV - Moon 4 - Caldari Navy Assembly Plant**.
Send Claude the values in **bold brackets**.

## 1. Sales tax and broker fee (2 min)
1. Open the inventory (item hangar). Right-click any cheap item → **Sell This Item**.
2. Switch to **Advanced** mode if needed (button at the bottom), so you can set a price instead of selling instantly.
3. The bottom of the window shows **Broker's Fee** and **Sales Tax**, each with a percentage.
4. Write down **[broker %]** and **[sales tax %]**. Close the window without selling.

Expected: broker 1.5% (lower if you have standings), sales tax about 3.37%.

## 2. Relist fee and price ticks (3 min, costs a few hundred ISK)
1. List that cheap item for sale at roughly double its normal price, so nobody buys it.
2. Market → **My Orders** → right-click the order → **Modify Order**.
3. Type a price with 5+ significant digits (e.g. `12,345,678`). Does the game reject it or round it?
   **[what happens]**
4. Lower the price by a small amount. The window shows the fee for the change. **[old price, new price, fee]**
5. Cancel the order.

## 3. Order slots and skills (2 min)
1. Market → **My Orders**: the window shows remaining and maximum orders. **[max orders]**
2. Character Sheet → **Skills → Trade**: levels of **[Procurement, Visibility, Daytrading,
   Marketing, Wholesale, Tycoon, Advanced Broker Relations]**.
3. Character Sheet → **Skills → Neural Enhancement**: levels of **[Infomorph Psychology,
   Infomorph Synchronizing]** (number of jump clones, and how often you can jump).

## 4. Standings (1 min)
Character Sheet → **Standings** → search **Caldari State** and **Caldari Navy**, and also
**Amarr Empire** and **Emperor Family** if you know you'll use Amarr. Use the *effective*
value shown on hover. **[values]**

## 5. Jump clone availability (2 min)
1. In Jita 4-4: Station services → **Clone Bay** (or Medical) → is **Install Jump Clone**
   available, or does it say a standing is required? **[result]**
2. If not available, note which player structure in Jita (e.g. the Perimeter Keepstar) you
   can dock at and whether it has a clone bay. **[name, yes/no]**
